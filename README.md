## About

I design and run cloud platforms that stay up.

Currently at **IKONIC**, where I own multi region AWS strategy, large scale Amazon EKS clusters and the modular Terraform frameworks behind them. Before that I automated fleets of Linux servers at Octaloop Technologies and kept mission critical environments stable at Al Nafi.

My work sits where infrastructure meets business continuity: reproducible environments, least privilege by default, observability that actually shortens incidents, and delivery pipelines that ship safely rather than merely quickly. I also build and serve ML workloads in production, from GPU tuned containers through to FastAPI inference endpoints.

**What I am hands on with right now**

* Multi region AWS and Amazon EKS at production scale
* Neo4j Enterprise cluster migrations with zero data loss
* GitOps delivery through ArgoCD, Helm and GitHub Actions
* DevSecOps gates with Trivy, Snyk and SonarQube
